# Security Policy

This policy covers LocalAir on **F00053AA Aura Air Rev 1.0** hardware only.
Security reports for other hardware variants may not be actionable.

If you believe you have found a security issue in LocalAir, please do not
file it as a public issue.

## How to report

- Use GitHub private vulnerability reporting from this repository's Security tab.
- If private reporting is unavailable, open a minimal public issue asking me for a private contact. Do not include exploit details in that issue.

## What to include

- A short summary of the issue
- The affected firmware version or commit
- Reproduction steps
- Any logs or traces that help confirm impact

Please avoid including secrets, access tokens, or live device identifiers in a
public report.
