# Support

LocalAir is local firmware for the **F00053AA Aura Air Rev 1.0** purifier (Particle P1, Kickstarter-era hardware discontinued after Aura Air's bankruptcy).
It is not supported on later Aura Air hardware, enterprise models, or rereleased devices.
Support is limited to owners who can flash Particle P1 firmware.

Use GitHub issues for reproducible bugs, build failures, documentation gaps, and hardware observations that do not contain secrets or live device identifiers.

For security reports, use `SECURITY.md`.
Do not post Wi-Fi credentials, access tokens, Particle device IDs, private IP screenshots, or private lab traces in public issues.
